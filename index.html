Held-out validation

Predicting standardised-test composite scores from multimodal brain data

Sibling repo to the TCNL Quanta multimodal brain-age stack (n = 427). Same frozen 80/20 age × sex stratified split (341 train / 86 held-out), same modality blocks — but the targets are composite cognitive and motor scores instead of chronological age. Chronological age is intentionally excluded from the feature set (the targets are already publisher-age-normed / age-scaled). The model is run independently at three score levels — RAW, SCALED, and NORM — because the publisher's raw → scaled → norm transformation is non-linear and the three carry slightly different signal-to-noise.

Launch interactive demo→ live on Streamlit Cloud

RAW SCALED NORM

All seven blocks of features are shared across levels: BEH (199) · EEG + PSD (659) · MRI (1094) · DTI ROI (90) · DL SFCN+Pyment (71) · rs-fMRI FC PCA-50 · SEX (1). Per-block RidgeCV → RidgeCV meta-stack; 5-fold inner CV; one refit on the full 341 train subjects → single held-out prediction. Each level's target set drops any composite that is an exact linear combination of the others kept at the same level (e.g. MEMORY_*_ImmMem).
